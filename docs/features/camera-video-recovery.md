# 相机视频安全恢复助手

当前版本提供 Sony 相机卡已有 `.img` / `.raw` 镜像的只读分析和安全直恢。入口位于“图片小工具 → 存储卡视频恢复”。

## 安全边界

- 镜像始终以 `FileAccess.Read` 打开，不修改原卡、FAT、allocation bitmap 或目录项。
- 不运行 CHKDSK，不提供写回、格式化、分区修复或系统盘 override。
- MP4 box 的大小、偏移和扫描数量均有边界；损坏声明不能越过镜像长度。
- 只有同时具备 `ftyp`、`mdat`、`moov` 和 sample tables 的非碎片候选可直接恢复。
- 其他候选只显示为 `EXPERIMENTAL`，没有默认恢复能力。
- 输出先永久保留 raw candidate，再生成 MP4 副本、SHA-256、JSON 与 Markdown 报告；现有输出不会覆盖。

## 当前范围

已实现附件计划 Phase 1–3 的本地 C# 安全路径：打开镜像、exFAT 识别、受限 MP4 扫描、候选分类、安全副本、哈希和报告。物理盘枚举、UAC 镜像器和进程重连属于后续独立高权限阶段；在完整系统盘映射、源盘输出门禁和独立进程协议就绪前不得暴露入口。
