# Hanabe macOS 版界面设计

> 设计稿（画布，可直接看、可评论）：https://claude.ai/artifact/BFcTYGVkbXMZaSwa7v3VPF
> 画板：主页 · 导入（检查确认）· 照片图库 · 人物查找 · 地图照片 · 图片小工具 · 设计规范。
> 本文件是画布的文字版，给执行 Agent 照做。功能清单与任务顺序见根目录 `AGENT_HANDOFF_MACOS.md`。

## 1. 总原则

- **功能、文字、步骤顺序与 Windows 版完全一致**；只有窗口外壳与快捷键（Ctrl → ⌘）按 macOS 习惯改。
- 视觉沿用 Hanabe：深紫莓渐变底 + 白色半透明玻璃卡片 + 樱粉强调色 + 吉祥物立绘。
- 密度比 Windows 版高一号，贴近 macOS 原生应用（正文 13 px、按钮高 30 px）。

## 3. 窗口外壳

- 无标题栏文字：`ExtendClientAreaToDecorationsHint = true`，红绿灯按钮浮在侧栏左上角（侧栏顶部留 26 px）。
- 侧栏 232 px：Logo + “Hanabe / 照片工作台”；分组“工作台”（主页、导入照片、照片图库、自定义相册、人物查找、地图照片）和“工具”（图片小工具、日期文件夹）；底部为当前存储卡小卡片（名称、进度、文件数）；设置在菜单栏和侧栏最底部。
- 侧栏可收成 72 px 图标栏（⌃⌘S，对应 Windows 窄侧栏）；图库、人物、地图、工具页默认图标栏，为内容让位。
- 每页顶部 52 px 工具栏：页面名（13 Semibold）+ 本页分段控件 + 右侧搜索框（320 px，占位“搜照片，或 ⌘↩ 让 AI 帮你做”，右端 ✦）+ 通知按钮。

## 4. 各页面

### 主页（画板“主页”）
两列网格：左列 Hero（手写体“Keep your memories”、问候语、最近拍摄与下一个日程、主按钮“导入照片 ⌘I”和次按钮“打开图库”、右侧立绘 190 px 宽）；下方两张卡：拍摄频率（近 12 周柱状，最新一周实心强调色）、交付进度（每个拍摄日一条进度：修后 / 原片，已交付用成功色）。右列 360 px 一张长卡：日程安排、存储空间（强调色 → RAW 色渐变条）、快速操作 2×2。

### 导入（画板“导入 · 检查确认”）
工具栏中间是三段步骤控件（✓ 选择来源 / 2 检查确认 / 3 导入），右侧“导入设置”按钮弹出面板。
检查页：四张数字卡（组数、总大小、拍摄日、重复数；重复卡用强调色底）→ 每个日期一张卡（两列）：日期 26 Bold + 星期 + 组数大小、右上重复徽章、5 张缩略图 + “+N”、分类比例条（8 px，多色）+ 图例、分隔线、“放到”+ 目标文件夹路径、处理方式下拉 + 备注输入 → “查看全部素材（N 组）”次按钮 → 底部操作条：来源胶囊、校验后移动复选、重新选择来源链接、主按钮“开始导入 →”。
选择来源与导入中 / 完成三个状态与当前 Mac 第一阶段实现一致，套用本规范的颜色和尺寸即可。

### 照片图库（画板“照片图库”）
四栏：图标栏 72 · 日期列表 220（按月分组，选中项强调色 22% 底，右侧数量；下方“智能筛选”：4 星以上、待修图、相似照片）· 照片网格（工具栏有“网格 / 平铺 / 矩形树图”与“全部 / RAW / JPG / 修后 / 视频”两组分段控件，搜索支持语义描述）· 信息面板 280（⌥⌘I 开关：预览、文件名 + 伴随文件、评分星、EXIF、人物与标签胶囊、快捷键提示）。
选中缩略图：2 px 强调色描边。空格 = 快速预览大图（独立看图窗口，左右键切换）；1–5 评分；⌘⌫ 移到废纸篓。

### 人物查找（画板“人物查找”）
工具栏：“人物相册 / 按脸查找”分段、右侧统计“328 人 · 27 已命名 · 全部在本机完成”、搜索名字、排序下拉。
内容：“已命名”一排 112 px 圆形头像，强调色 3 px 外圈，右下照片数徽章；“未命名”一排 88 px 头像，名字下方是“人物 N · 数量”，点名字可改；底部提示条“还有 N 个只出现 1–2 次的路人，已收起 · 全部显示”。
点头像进入人物详情（与 Windows 版相同：大头像 + 名字输入 + 复核 / 合并 / 保存；照片网格显示整张照片不裁切；照片标题行右侧放移出误识别 / 拆分 / 撤销）。

### 地图照片（画板“地图照片”）
原生瓦片地图铺满（不用网页控件），浮在上面的控件都用 85–90% 不透明的深色玻璃：左上标题 + 有位置照片数、时间范围分段；右上缩放按钮。照片聚合点 = 缩略图方块 + 数量徽章，选中点用强调色描边与强调色徽章。底部浮层：地点名、张数与拍摄日、“在图库中打开”、一排 8 张缩略图、瓦片署名。

### 图片小工具（画板“图片小工具”）
4 列卡片网格，每张卡：40 px 图标底块（各用一个分类色）、工具名 15 Semibold、一句说明。工具：批量压缩、水印、拼图、九宫格切图、像素画、S-Log3 还原、存储卡恢复、查重与隔离区。可把照片直接拖到卡片上开始；每个工具在独立窗口打开（可并排）。

### 未画出的页面（按同一套规则做）
- **自定义相册**：左侧相册列表（同图库日期列表样式）+ 右侧照片网格；新建相册按钮在列表顶部。
- **日期文件夹**：按月的热力日历（格子颜色 = 当天文件数，强调色深浅）+ 选中日期的备注编辑，与 Windows 版相同。
- **设置**：macOS 偏好设置窗口（⌘,），顶部图标分页：通用 · 照片库与导入 · 外观 · 人物识别 · AI 与 Agent · 关于；每页内容与 Windows 设置中心一一对应。
- **桌面助手**：主窗口最小化时出现的透明置顶小窗，Q 版立绘 + 当前任务进度，行为与 `HanabeAssistantWindowPolicy` 相同。
- **AI 助手面板**：从搜索框下拉的 480 px 玻璃浮层，对话气泡（用户在右、强调色容器；AI 在左、白 8%），操作记录用小胶囊。
- **右键菜单**：圆角 14 玻璃面板 + 投影，勾选框为粉色圆角方块（与 Windows 版统一后的样式一致）；同时提供 macOS 原生菜单栏里的对应项。

## 5. macOS 习惯（必须做）

- 菜单栏：Hanabe › 关于 / 偏好设置… ⌘, / 退出 ⌘Q；文件 › 导入… ⌘I；显示 › 收起侧栏 ⌃⌘S、信息面板 ⌥⌘I；前往 › 各功能页 ⌘1–⌘9。
- ⌘F 聚焦搜索；⌘↩ 把搜索框内容交给 AI。
- 插入存储卡时发系统通知“检测到 SONY α7 IV，1,288 个文件”，点通知进入导入。
- 文件夹拖到 Dock 图标也能开始导入。
- 删除一律进废纸篓，不直接删除。
