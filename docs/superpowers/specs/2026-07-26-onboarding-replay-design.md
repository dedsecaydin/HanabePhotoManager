# 新手教程再次体验设计

## 目标

在“设置 → 常规”提供“再次体验新手教程”入口。用户点击后立即离开设置页并从第一步播放教程，完成或跳过后保持已完成状态，不影响后续正常启动。

## 交互

- 常规设置新增“新手教程”区块，包含用途说明和“再次体验新手教程”按钮。
- 教程采用全局遮罩卡片，提供“上一步”“下一步”“跳过”“完成”。
- 三个步骤依次介绍：
  1. 设置唯一的图库根目录。
  2. 在导入页添加一个或多个来源文件夹。
  3. 扫描来源、检查队列并开始导入。
- 重播时先导航到与当前步骤对应的一级页面，再显示该步骤内容。
- 第一步隐藏“上一步”；最后一步将“下一步”替换为“完成”。
- “跳过”和“完成”都会关闭教程并把 `HasCompletedOnboarding` 保存为 `true`。

## 状态与数据流

- `OnboardingStep` 表示当前步骤，`IsOnboardingVisible` 控制遮罩。
- `ReplayOnboardingCommand` 将步骤重置为第一步、显示遮罩并导航到设置中的照片库入口。
- `PreviousOnboardingStepCommand` 和 `NextOnboardingStepCommand` 改变步骤并导航到对应页面。
- 不改变现有 settings.json schema；继续复用 `HasCompletedOnboarding`。

## 错误处理

- 状态保存失败不会阻止遮罩关闭，错误通过现有状态信息呈现。
- 重播不依赖图库或来源目录已经配置，缺失配置只作为教程说明，不阻塞步骤切换。

## 验证

- 测试设置页存在重播入口并绑定正确命令。
- 测试重播会显示第一步，前进/后退边界正确。
- 测试完成和跳过均关闭教程并保存完成状态。
- 运行完整 `dotnet test -clp:Summary` 和 Release 构建。
