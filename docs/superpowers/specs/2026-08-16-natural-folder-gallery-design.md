# 自然文件夹图库与设置视觉修正设计

## 目标

将照片图库重写为单一纵向自然滚动的文件夹分组流，同时保留现有筛选、缩略图缩放、多选和无边框查看器能力；修正设置导航与导入高级选项的视觉层级。

## 图库结构

- 无任何筛选条件时浏览全部可展示媒体。
- 数据流固定为“分组标题 → 该组媒体 → 下一分组标题 → 下一组媒体”。
- 不吸顶、不折叠、不分页，不保留旧日期展开状态。
- 默认分组标题为解析后的日期标题；设置可切换为实际文件夹名或“日期标题 + 文件夹名”。
- 只有一个纵向滚动所有者；缩略图滑块只改变卡片尺寸、列数和布局，不改变当前过滤范围。
- XML 永不作为独立图库项目。与视频同目录且同基本文件名的 XML 仅令视频卡片显示 `XML` 徽标。
- 视频截帧 JPG 仅作为对应视频卡片封面，不进入图库项目集合；双击卡片打开原视频。
- 双击照片或视频继续打开现有无边框查看器。

## 多选

- 多选入口使用 Switch 外观，关闭时保持单选/双击行为，开启时点击卡片切换选择。
- 被选中的卡片使用单层深色语义背景，不叠加多重描边。

## 设置

- “照片库与导入”新增“图库分组标题”设置，选项为：解析后的日期标题（默认）、实际文件夹名称、日期标题 + 文件夹名称。
- 设置二级菜单选中态使用圆角矩形。
- 应用左侧一级导航图标水平居中，中文标签完整显示；选中态只保留单层浅色背景，不显示内部深色指示。
- 导入高级选项改为紧凑的分组设置行：标题与说明在左，Switch、下拉或输入控件在右；减少大面积浅紫色嵌套卡片。

## 验证

- 自动化覆盖：标题模式持久化、自然分组顺序、XML 隐藏与视频 XML 标记、截帧排除、多选视觉契约、查看器双击绑定保留。
- Release 构建必须 0 警告 0 错误，全量测试通过。
