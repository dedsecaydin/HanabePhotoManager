# Hanabe Photo Manager WPF 安装外壳设计

## 目标

以独立 WPF 引导程序替换 WiX Standard Bootstrapper Application 的界面层，同时保留 MSI 作为安装事务、升级和卸载的唯一执行者。安装器必须能够正常启动，使用与主应用一致的品牌图标，并提供克制的黑白中性色浅色、深色外观。

## 用户流程

安装流程固定为四步：

1. 欢迎：展示应用图标、版本、安装位置和空间提示。
2. 使用须知：在内嵌滚动区域展示完整须知；只有滚动到末尾后，“我已阅读并同意”才可用，选中后才允许继续。
3. 安装：展示确定进度、当前阶段、取消入口和可读的失败信息。
4. 完成：提供启动应用和关闭安装器两个操作。

返回上一步时保留安装位置和须知阅读状态。安装开始后禁止返回，取消操作必须二次确认。失败时保留日志路径并允许复制错误摘要。

## 架构

新增独立的 `.NET 8 WPF` 安装外壳项目。外壳只负责交互、主题、状态和启动安装引擎，不直接复制应用文件。

- `InstallerShellViewModel`：维护步骤、按钮可用状态、安装路径与进度。
- `LicenseReadGate`：根据滚动容器的 `VerticalOffset + ViewportHeight >= ExtentHeight` 判定是否读到末尾，并兼容内容无需滚动的情况。
- `InstallerEngine`：以受控参数启动打包后的 WiX Bundle/MSI，读取退出码并映射为成功、取消、需重启或失败。
- `InstallerThemeManager`：跟随 Windows 应用主题，允许用户手动切换浅色与深色。
- `InstallerLogService`：将外壳日志和 MSI 日志写入本机临时目录，不写入 OneDrive。

外壳与 MSI 之间仅通过明确的命令行参数、退出码和日志文件通信。安装目录必须经过绝对路径校验；提升权限只在用户点击“安装”后触发。

## 视觉规范

整体参考微信、QQ、Discord 安装器的低认知负担，而不复制其品牌组件：单窗口、单主操作、少量层级、清晰进度。

- 窗口采用圆角主体、柔和边界和克制阴影。
- 浅色主题使用白色、暖灰、近黑文字；深色主题使用炭黑、深灰、近白文字。
- 品牌紫只用于主按钮、焦点和进度，不使用多色渐变或高饱和彩色卡片。
- 所有正文、说明、禁用态和输入文字使用语义资源，浅色和深色资源键完全一致。
- 安装器窗口图标、任务栏图标、程序图标统一使用 `HanabeApp.ico`；内容区分别使用透明深色背景版本和白色背景版本，并随主题切换。
- 主按钮、输入框、步骤卡和滚动容器均使用统一圆角，不叠加多层边框。

## 打包方式

发布脚本依次生成自包含应用、MSI、WPF 安装外壳，最后输出单一可分发安装程序。最终文件继续命名为 `HanabePhotoManager-Setup-x64.exe`。外壳依赖必须自包含，目标电脑无需预装 .NET Desktop Runtime。

在正式迁移完成前保留现有 WiX Bundle 构建作为回退路径；新外壳通过测试后再成为默认产物。

## 验证

- 单元测试：须知滚动阈值、步骤状态机、退出码映射、安装路径校验、主题资源键一致性。
- 构建测试：Release、警告视为错误、自包含发布、安装器静态作者测试。
- 手动验证：干净 Windows 环境启动、滚动门禁、取消、失败、安装、升级、卸载、启动应用。
- 视觉验证：浅色、深色、100%/125%/150% DPI、小窗口、长中文路径、键盘导航和文字对比度。

## 不在本次范围

- 不重写 MSI 的升级、卸载和文件部署逻辑。
- 不增加账户、联网下载、广告或自动更新页面。
- 不在安装开始前请求管理员权限。
