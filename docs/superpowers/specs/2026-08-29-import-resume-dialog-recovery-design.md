# 导入续传提示与旧记录恢复设计

## 目标

将启动时原生“是/否”提示替换为主题一致、语义明确的续传窗口，并修复点击继续后旧版断点记录因缺少 `TargetDateDirectory` 而无可见反应的问题。

## 交互

窗口显示待恢复媒体组数、日期数和传输模式，提供：

- `继续传输`：关闭窗口、导航到导入页、立即显示“正在恢复上次导入”，然后恢复；
- `放弃记录`：二次明确说明只删除续传记录，不删除已导入或源文件，然后清除记录；
- `稍后处理`：保留记录并关闭窗口，本次不恢复。

窗口使用现有 `Dialog.Window`、`Dialog.Surface` 和共享按钮样式，支持 Enter、Escape 与自动化名称。

## 旧记录兼容

新记录继续使用持久化的绝对 `TargetDateDirectory`。旧记录缺少该字段时，按 `LibraryRoot\月\MM.DD` 推导旧版目标；若规范日期目录已带备注，则扫描同日期候选：唯一候选时使用它，多个候选时停止并要求重新确认，绝不猜选。解析失败必须在导入页和主题提示中可见，并保留记录。

## 验证

覆盖旧记录唯一目录迁移、多个同日期目录拒绝猜测、新记录路径保持、放弃/稍后语义和主题窗口契约；完成 Release 构建、全量测试、覆盖发布与启动。
