# 设置音效分区与安全确认统一设计

## 目标

将音效从外观页拆成设置左侧独立“音效”分区，并将移动导入前的原生 Windows MessageBox 替换为使用 Hanabe 设计系统的应用内安全确认窗口。

## 设置结构

左侧分区顺序为：外观、音效、常规、照片库与导入、浏览与 AI、高级。音效页包含总开关、A/B/混合风格、音量、安静模式和三个试听按钮。“重复检测完成且需要处理时唤回主窗口”属于导入行为，移入照片库与导入页。

## 安全确认

新增 `ImportMoveSafetyConfirmationWindow`，复用 `Dialog.Window`、`Dialog.Surface`、共享文本与按钮样式。内容明确说明：仅在复制、SHA-256 校验和备注写入成功后删除来源；提供“返回检查”和“确认移动并导入”，默认焦点放在安全的返回按钮，Escape 取消，确认按钮不使用危险删除色。

## 验证

资源测试确认不再调用该 MessageBox、独立音效导航/内容存在、设置绑定保持不变；Release 构建、完整测试、发布与运行验证。
