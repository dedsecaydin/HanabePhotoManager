# 图片切图与板块对比度设计

日期：2026-10-28
状态：用户已确认；已实现并验证，详见 agent-change-log。

## 当前基础与方案选择
图片工具现有压缩、传统拼接、智能拼图入口，当前工作区存在用户未提交改动，全部保留。
推荐在现有图片工具中增加独立切图入口，复用主题和图片解码/导出能力。备选是在拼图中加入模式（入口较隐蔽），或创建独立顶级导航（增加导航负担）。

## 功能与交互
- 中分：等分两张，支持横切/竖切。
- 六分：两行三列或三行两列；九宫格：三行三列。
- 导入一张图片，在预览中拖动裁切区域，自主决定保留位置；提供原图比例和方形选区，调整选区大小并限制在图像边界内。
- 实时显示网格、编号、整体选区尺寸和单块尺寸；按从左到右、从上到下导出。
- 使用整数边界分割，处理不能被整除的尺寸，避免漏像素或重叠；不做默认放大。
- 支持 JPEG 和 PNG，用户选择输出目录，默认建议 D 盘项目数据下的独立导出目录；原图保持不变，文件名冲突时生成唯一名称。
- 提供导出进度、完成位置和可恢复错误提示；导出期间防止重复操作。

## UI 与对比度
左侧选择图片和分割模式，中间大图预览，右侧裁切与导出设置。
新增切图板块使用共享语义资源，提高正文/说明文字、区域背景、边界、选中态与焦点的可辨识度，同时兼容 Light/Dark。先覆盖图片工具相关板块，不扩展为整站换肤。

## 实现边界与验收
分割边界计算与编码输出独立于预览交互，复用现有组件，不修改导入、图库和既有拼图数据流。
验证二分/六分/九宫格、横竖方向、边缘拖动、小图和非整除尺寸、导出失败与重名保护；运行 Release 构建及相关测试，实机检查 Light/Dark、键盘焦点与预览到导出位置一致性。
