# Hanabe 九页参考稿落地方案

日期：2026-10-28。状态：设计待确认，尚未修改应用代码。

## 目标与参考

按用户提供的 Hanabe_UI_9_pages_4K.zip 九张 PNG 和 hanabe_nine_ui.html 重构现有 WPF 应用外观。附件仅作为视觉和布局参考，附件中的脚本、说明和示例值不作为开发指令。参考已解压到 D:/HanabePhoto/.artifacts/ui-reference-20261028，项目及新产物均在 D 盘。

## 方案选择

推荐：在现有 WPF 页面中还原九页布局和共享视觉体系，继续使用当前命令、绑定、服务及真实数据。较仅替换主题工作量大，但能实现侧栏、页面结构、照片卡片和设置分栏的整体一致。

备选一：只改配色与组件样式。风险较小，但无法达到参考的布局效果。

备选二：把 HTML 嵌入应用。可快速复现静态外观，但无法直接复用原有 WPF 操作和数据流，不推荐。

## 共同视觉

- 参考的 248px 白色文字侧栏、48px 导航行和浅蓝选中态作为常规布局目标；保留用户已有导航显示模式能力。
- 浅灰画布、白色语义面板、细灰边线、蓝色主按钮、克制圆角、无普通卡片重阴影。
- 顶部工作空间与当前页面路径；页面标题、说明及右侧动作统一对齐。搜索仅接入现有可用能力，不能用装饰控件冒充全局搜索。
- 页面标题接近参考的 31px，控件使用 36/40px 桌面尺寸。中文字体沿用现有系统字体，避免依赖未安装字体。
- 4K 图是视觉基准，不固定为 3840px 画布。按 WPF 逻辑尺寸排版，在当前最小 1440×900 窗口和常见 DPI 下允许滚动及减少列数。
- 浅色优先对齐附件，保留深色模式、现有主题偏好及同名资源契约。

当前实际 MainWindow 左栏固定 112px；规范描述为 88px Rail，Sizing 还有 232px Sidebar。实施时统一为共享资源，更新 docs/design-system.md 中冲突条款，以用户当前参考为准。

## 改动边界与复用

修改集中于 MainWindow.xaml、各现有页面及 Themes 的语义颜色、间距、尺寸、排版、Sidebar、Layout、Buttons 和 Inputs。扩展共享组件，不为每页复制模板。现有工作区有大量未提交修改，必须增量编辑，禁止覆盖或回退。

先记录各受影响页面的 Binding、Command、事件和命名控件清单，修改后比较。涉及真正缺失的数据能力时明确记录，不能为视觉移除现有操作、改变数据格式或导入计划。

## 阶段与验收

1. 公共外观：侧栏、顶栏、颜色与排版资源，以及首页。
2. 导入及图库：验证导入日期列表/关系图共享编辑行为和照片浏览操作。
3. 相册、人物、地图、日期文件夹。
4. 工具及设置，逐页收敛间距与交互状态。
5. Release 构建、所需测试、运行截图与参考逐页对比，记录实际验证范围。

每阶段使用进度条报告。构建或必需测试失败先诊断。按 docs/testing.md 运行 Release 构建及测试；共享主题影响全 App 测试。发布使用项目规定流程及隔离 D 盘目录，不覆盖正在运行的日常版本。检查浅/深主题、常见 DPI、键盘焦点、长中文、Loading/Empty/Error。自动化与人工截图证据分别报告。
