# 整体界面优化：连续工作区与功能分区

当前基础为 alpha.27。使用已有设计体系，不重写业务；用户已要求直接实施。

## 修改前功能清单

- MainWindow：八个主导航入口、可重排导航、明暗主题、窗口按钮、状态/任务进度、上下文帮助、图库筛选/虚拟化/Inspector。
- 工具：压缩、智能拼图、传统拼接、水印、像素画、S-Log3、独立媒体恢复；已有详情工作台和返回操作。
- 设置：分类导航、搜索、锚点目录、自动保存。
- 新窗口：场次检测/修正/拆分/合并/撤销，拼图候选/主图/导出，视频高级配置/队列/预览/取消。

## 设计决策

采用现有共享 Layout、Sidebar、Button、Spacing 资源渐进调整。保留照片卡片，弱化页外框；侧栏以细分隔接入连续背景；状态栏保持固定位置；页面标题使用桌面 Title 层级。工具首页拆为图片处理、视频处理、媒体恢复三个可扫读区，入口用小图标加文字描述代替海报式色块。媒体恢复保持独立且显示只读说明。

替代方案：仅改配色无法解决板块结构；完全重做导航会触碰稳定交互。本次均不采用。保持当前默认主题和用户主题偏好。
