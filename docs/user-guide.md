# Hanabe Photo Manager 功能说明

## HEIF 原件与 JPG 自动导入

导入 `.HEIF`、`.HEIC`、`.HIF` 时，程序会保留原件，并在“JPG生图”中额外生成 JPG。已有同名 JPG 不会被覆盖；原件内容保持不变。转换失败会显示原因并保留恢复记录，可稍后继续。重复导入时跳过已有原件，缺少生成的 JPG 时会补齐；这不会批量处理尚未选中导入的其他文件。

精确查重优先复用有效指纹，目标文件的备注按批建立索引，后续可复用未变化文件的缓存。首次检查没有指纹的大文件仍需要读取内容；查重期间会显示当前文件和已检查数量。

## S-Log3 视频还原

在“图片小工具”中打开“S-Log3 视频还原”，添加一个或多个视频，选择与拍摄色域匹配、目标为 Rec.709 的 `.cube` LUT。先选中一个视频点“预览所选前 10 秒”，确认画面后选择导出目录并点“批量导出”。导出的是新的 MP4，原视频保留。程序优先使用随包附带的 `tools\ffmpeg.exe`，直接打开程序也能使用，无需额外配置 PATH；缺少工具时请重新复制完整程序包。默认导出目录为 `C:\HanabePhoto\SLog3Exports`，预览临时文件位于 C 盘项目目录内。

Sony 的 [Look Profile 下载页](https://www.sony.com/electronics/support/software/00263050)提供 S-Gamut3.Cine/S-Log3 等转换 LUT；选择前请核对相机拍摄时的色域设置。

应用内每个页面右下角都有“本页说明”。它会跟随当前页面自动切换，包含页面用途、推荐操作顺序和安全提示。以下内容与应用内说明保持一致，适合首次使用或查找功能时参考。

## 安全提示

- 导入中断时优先使用“继续导入”；“放弃恢复记录”只移除恢复记录，不删除已经导入的文件。
- 重复检测会优先复用未变化文件的 SHA-256 和视觉指纹；删除或覆盖前仍会再次校验。
- 自定义相册的“移除引用”不会删除磁盘中的原文件。
- 水印、压缩和恢复默认写入新目录或新文件；导出前请确认输出位置。
- 恢复页的时间筛选使用存储卡目录记录的本地最后写入时间；目录已损坏或丢失时需要完整扫描。

## 视频封面与设备提醒

- Sony 视频 Cxxxx.MP4 的配套 CxxxxT01.JPG 用作视频封面，不再独立出现在浏览列表。文件仍保留在磁盘上；没有对应视频的 JPG 继续显示。
- 设置 → 常规 → 检测存储卡并提示导入：应用运行时检查可移动磁盘，有照片或视频时显示目标照片库并询问是否进入导入页。进入后检查文件和目标位置，再开始导入。
- 同次插入只提醒一次，忙碌时暂缓检测；当前不检测 MTP 相机或被系统归为固定磁盘的 USB 硬盘。
## 导入日期的两种查看方式

进入“确认日期文件夹”后，关闭“关系图”开关使用原列表，打开开关查看日期与素材的关系。大圈表示一个拍摄日期及它的目标文件夹，小圈显示前两个素材；点击“+剩余数量”或日期，可以查看同日全部媒体并编辑目标。月份可折叠，素材可点击预览。切换视图保留备注、处理方式、已有文件夹选择和校验结果，最后仍需点击“确认并开始导入”。

## 图片切图
进入图片工具 → 切图，选择图片和中分/六分/九宫格。选择方形或原图比例，调整大小并拖动选区；水平/垂直滑块与预览方向键可微调位置。编号按从左到右、从上到下导出。选择 D 盘输出目录，选择 PNG 或取消勾选导出 JPEG，点击导出。每次结果独立保存，可打开导出文件夹；取消会清理不完整结果。
