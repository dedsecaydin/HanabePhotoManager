# Hanabe Photo Manager 功能说明

应用内每个页面右下角都有“本页说明”。它会跟随当前页面自动切换，包含页面用途、推荐操作顺序和安全提示。以下内容与应用内说明保持一致，适合首次使用或查找功能时参考。

## 页面速查

| 页面 | 用途 | 推荐顺序 |
|---|---|---|
| 主页 | 选择图库、查看设备和最近日期 | 选择图库 → 查看设备/日期 → 进入功能 |
| 导入照片 | 分析来源并按日期导入 | 选来源 → 分析 → 确认日期 → 导入；中断后继续 |
| 照片图库 | 按日期、分类、搜索条件浏览 | 筛选 → 查看检查器 → 执行操作 |
| 自定义相册 | 引用任意文件夹集中查看 | 添加文件夹 → 查看详情 → 刷新或移除引用 |
| 人物查找 | 根据参考人脸查找相似人物 | 参考照片 → 范围/强度 → 查找 → 双击结果 |
| 地图照片 | 查看和补充照片位置 | 选择地点/照片 → 查看地图 → 手动标记 → 保存 |
| 图片小工具 | 压缩、拼接和图片处理 | 选工具 → 添加文件 → 调参预览 → 批量处理 |
| 批量水印 | 生成带水印的新文件 | 选输入 → 选水印 → 调整 → 预览 → 导出 |
| 日期文件夹 | 批量维护日期目录和备注 | 选日期 → 编辑备注 → 检查预览 → 保存 |
| 相机照片与视频恢复 | 从可移动存储卡或镜像中只读查找照片与 MP4 视频 | 选择设备并点“使用此设备”，或打开镜像 → 设时间范围 → 扫描 → 查证据 → 导出 |

恢复输出自动安排在 `D:\HanabeRecovery\日期\时间_来源_任务编号`，无需反复选择文件夹。同秒启动的不同任务也不会覆盖。直接扫描设备时，Windows 会请求独立只读进程的管理员权限；拒绝权限后本次扫描停止。系统物理盘、与 D 盘同一物理盘的来源不能扫描。输出目录不可用、空间不足或经过目录链接时会显示原因并停止，不会悄悄改到其他盘。

直接扫描目前支持有盘符的可移动存储卡和 U 盘，读取包含删除数据的卷内空间，不先生成整盘镜像。无盘符设备、固定 USB 硬盘和丢失分区仍须使用镜像入口；目录丢失时按完整扫描查找，碎片文件不自动拼接。设备拔出、更换或取消后，请重新开始扫描，旧结果不能跨连接直接导出。设备候选当前显示结构证据，导出后可用“打开 / 播放上次恢复文件”检查画面。

## 安全提示

- 导入中断时优先使用“继续导入”；“放弃恢复记录”只移除恢复记录，不删除已经导入的文件。
- 重复检测会优先复用未变化文件的 SHA-256 和视觉指纹；删除或覆盖前仍会再次校验。
- 自定义相册的“移除引用”不会删除磁盘中的原文件。
- 水印、压缩和恢复默认写入新目录或新文件；导出前请确认输出位置。
- 恢复页的时间筛选使用存储卡目录记录的本地最后写入时间；目录已损坏或丢失时需要完整扫描。

## 视频封面与设备提醒

- Sony 视频 Cxxxx.MP4 的配套 CxxxxT01.JPG 用作视频封面，不再独立出现在浏览列表。文件仍保留在磁盘上；没有对应视频的 JPG 继续显示。
- 设置 → 常规 → 检测存储卡并提示导入：应用运行时检查可移动磁盘，有照片或视频时显示目标照片库并询问是否进入导入页。进入后检查文件和目标位置，再开始导入。
- 同次插入只提醒一次，忙碌时暂缓检测；当前不检测 MTP 相机或被系统归为固定磁盘的 USB 硬盘。
