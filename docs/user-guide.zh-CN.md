# Hanabe Photo Manager 使用说明

## 首次使用

1. 在“设置 → 照片库与导入”选择照片库根目录。
2. 进入“导入照片”，选择一个或多个来源文件夹，也可以把多个文件夹直接拖入来源区域。
3. 等待分析完成，检查日期归属、分类和重复项决定，再开始导入。
4. 导入完成后进入“照片图库”浏览全部内容。

应用不会要求把照片上传到云端。涉及移动、删除或重复处理时，请先保留独立备份。

## 照片图库

- 无筛选时按设置选择的方式显示全部照片，可按解析后的拍摄日期或原文件夹名称分组。
- 单击照片：在右侧 Inspector 显示文件、拍摄参数、日期与位置。
- 双击照片或视频：打开应用内无边框查看器。
- 滚轮：自然上下浏览各分组；日期/文件夹标题可展开或收起。
- `Ctrl + 滚轮`：以鼠标位置为中心调整缩略图/画布比例。
- 多选模式：开启后点击卡片进行选择，被选项目使用深色状态表示。
- XML 不单独显示；如果同名 XML 对应某个视频，视频卡片上会显示 XML 标记。

## 导入

- “选择来源文件夹”：选择单个目录。
- “选择多个文件夹”：一次加入多个相机卡或拍摄目录。
- 拖放：只接受文件夹，可一次拖入多个文件夹。
- 开始前可检查分类、目标日期和重复文件处理方式。
- 导入进行中以当前完成数/总数为准；导入摘要统计本次已经成功、跳过和失败的结果。
- 中断后如存在安全日志，可按提示继续未完成导入。

## 查看器

- 照片：滚轮缩放，按住鼠标拖动平移。
- 视频：播放/暂停、快进后退、倍速和进度定位。
- 移动鼠标可调出工具栏；沉浸状态下工具栏自动隐藏。
- `Esc` 先退出全屏，再次按下关闭查看器；方向键切换相邻媒体。

## 人物、地图和工具

- 人物查找：扫描本地照片后生成可重命名、合并的人物相册。
- 地图照片：读取 EXIF GPS；扫描进度会保存，后续从上次位置继续。
- 图片小工具：提供压缩、拼图、水印等批处理；输出前确认目标目录，避免覆盖原片。
- 自定义相册：引用现有文件夹，不会把原照片复制到另一个相册目录。

## 外接设备

应用检测到新的可移动盘后会询问是否备份。确认设备和目标目录无误后再进入导入；拒绝不会修改设备内容。

## 常见问题

- 右侧仍显示“未选择照片”：先关闭 Inspector 再重新单击卡片；若持续出现，请记录所处分组和文件名用于排查。
- RAW 没有预览：系统缺少对应相机 RAW 解码支持时会使用嵌入预览或占位图；原始文件仍可导入和管理。
- 设置保存失败且提示拒绝访问：选择当前用户可写的设置/照片库目录，不要使用受保护的系统目录。
- 地图首次加载较慢：首次需要初始化 WebView2 和缓存；后续扫描会使用检查点。
