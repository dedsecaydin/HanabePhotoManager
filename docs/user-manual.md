## 1. 快速开始

### 安装

- 本应用是 Windows 桌面程序，需要 **Windows 10 / 11** 与 **.NET 8 运行时**（安装包一般会自动带上，缺失时按提示安装即可）。
- 解压或安装完成后，双击 `HanabePhotoManager.exe` 启动。

### 首次启动

1. 首次启动会弹出 **「Hanabe 新手指南」**，分步骤介绍照片库、导入、AI、人物识别和批处理工具。可跟随操作，也可随时跳过；之后在 **设置 → 常规 → 再次查看新手指南** 可以重新打开。
2. 第一次使用需要指定 **照片库根目录**：
   - 在首页顶部点 **「选择库根目录」**，或在 **设置 → 照片库与导入 → 更改照片库** 中选择一个文件夹。
   - 照片库是应用唯一的数据根，所有导入的照片按 `月\日期\类别` 的目录结构存放。
   - 修改照片库后应用会重新扫描；启动时也会自动验证照片库，并在后台扫描新增文件。
3. 首页会显示照片库健康状态、已发现的日期数和媒体文件数。

### 最简使用路径

把相机 / 手机的文件夹拖进 **导入照片** 页 → 点 **「开始分析与导入」**（先分析分类生成导入队列，随后自动继续导入）→ 去 **照片图库** 浏览。

## 2. 界面总览

### 一体化标题栏（无边框窗口）

- 窗口没有传统系统标题栏，顶部就是应用自己的标题栏：
  - **右上角三个按钮**：最小化、最大化 / 还原、关闭。关闭键悬停时变红。
  - **拖拽移动**：按住顶部空白区域（或左上角圆形 Logo）拖动窗口。
  - **双击顶栏**：最大化 / 还原窗口。
  - 窗口四边保留 8px 拖拽边框，可以拉伸调整大小。

### 左侧导航栏

- 窄长的导航栏（默认图标 + 文字竖排），包含：

  | 导航项 | 作用 |
  |---|---|
  | 主页 | 照片库状态、最近照片、快速操作、当前连接设备 |
  | 导入照片 | 把新照片导入照片库 |
  | 照片图库 | 浏览、筛选、管理全部照片 |
  | 自定义相册 | 把任意磁盘文件夹加入"虚拟相册" |
  | 人物查找 | 扫描人物、按脸查找 |
  | 地图照片 | 按地点浏览照片、手动标记位置 |
  | 图片小工具 | 压缩 / 拼图 / 水印 / 微信发送 |
  | 网盘 | 百度网盘、夸克网盘 |
  | 设置（底部） | 全部设置项 |

- 底部还有 **明暗主题切换按钮**（🌙/☀️），点一下立即切换浅色 / 深色。
- 导航项支持：
  - **拖拽排序**（按住导航项拖动调整顺序，自动保存）。
  - **导航切换**：点击一级菜单项切换页面；支持拖拽排序；当前页高亮 + 滑动动画。
  - 显示样式可在 **设置 → 外观 → 导航菜单显示** 里改为"文字 / 图标 / 图标和文字"。

### 顶部与底部

- **顶栏**：显示当前页面标题与副标题；在主页时右侧有「选择库根目录」「刷新」按钮。
- **状态栏（底部）**：显示当前状态消息；有后台任务时显示进度条和百分比。
- 页面切换有 180ms 的淡入微移动画。

### 右侧 Inspector（检查器）

- 多个页面（浏览、导入、相册、网盘、设置）右侧都有固定 **320px 的 Inspector 面板**：
  - 浏览页：显示所选照片的文件信息 / 拍摄参数 / 时间与位置，以及快捷操作。
  - 导入页：导入设置、去重结果、本次导入摘要。
  - 设置页：当前主题实时预览、数据与存储、关于。

### 右下角悬浮按钮

- 照片图库页右下角有一个圆形 **「＋」按钮**，一键跳转到导入照片页。

## 3. 导入照片

导入页分为左（导入源）、中（导入队列）、右（导入设置）三栏。

### 选择来源

有以下几种方式：

- **拖入相机文件夹**：把相机 / 手机导出的整个文件夹拖到最上方的拖放区。应用会自动读取文件、自动分类、自动生成日期目录。
- **选择来源文件夹**：点「选择来源文件夹」，选整个目录。
- **选择多个文件**：点「选择多个文件」，挑出要导入的文件。

### 转移方式（二选一）

| 选项 | 含义 |
|---|---|
| 复制并保留源文件 | 导入后源文件原封不动（推荐，安全） |
| 校验后移动 / 删除源文件 | 确认复制无误后，把源文件移走 / 删除（节省空间） |

### 本地 AI 人物识别（可选开关）

- 打开后，导入的同时在本机识别照片中的人物（**只识别 JPG/JPEG**；同名 RAW 自动继承识别结果；视频跳过）。
- 所有处理都在本机完成，照片不会上传。

### 拖入后期 / 素材

- 有两个独立拖放区：**「修后」**（后期完成文件）和 **「素材」**（项目素材）。
- 无法判断归属的文件会停下来让你确认，不会乱放。

### 分析与导入

1. 点 **「开始分析与导入」**：应用读取来源 → 自动分类（RAW生图 / JPG生图 / 修后 / 视频 / action视频 / 素材 六类）→ 生成导入队列 → 自动继续导入。状态栏会显示进度。
2. 在中间的 **导入队列** 里检查结果：
   - 顶部显示目标日期、分析报告和操作提示。
   - 队列按 6 个分类分组展示，每张卡片上有：队列编号、分类角标、缩略图、文件名、大小、目标日期；识别出人物时还有 **人物标签**。
   - 个别文件会带 **「需要人工确认」** 角标，说明归属或分类拿不准。
   - 每张卡片可 **勾选/取消勾选**（决定是否导入），也可以在卡片右下角的下拉框里 **手动改分类**。
   - 分组较多时点「继续显示更多（剩余 N 张）」展开剩余项。
3. 分析完成后会自动开始导入；若队列里有需要人工确认的项目，会先停下提示你确认，确认后再点一次 **「开始分析与导入」** 即可继续导入（不会重复分析）：
   - 应用会先扫描图库已有内容 → 检查重复 → 逐个导入，进度条实时显示。
   - 遇到重复文件时弹出确认窗口，可以 **全部跳过（推荐）/ 全部仍导入 / 逐个选择**。
   - 导入过程中可点 **「取消导入」**。
4. 完成后右侧 **本次导入摘要** 显示：成功 / 跳过 / 失败 三个数字。

### 导入的几条规则

- **精确查重（SHA-256）**：始终开启，重复文件自动跳过。
- **相似照片审查（感知哈希）**：只做全库相似度审查，不会自动阻止导入。
- **修后目录只读保护（铁律）**：`修后` 文件夹永不写入、不可覆盖，无法关闭。
- 照片按 **拍摄日期** 归入 `月\日期` 目录，再按类别分文件夹；导入后去照片图库即可看到。

## 4. 浏览与管理照片

照片图库页是核心页面，从上到下是：浏览条件（可折叠）→ 左侧日期 / 人物面板 → 中间照片墙 → 右侧 Inspector。

### 日期筛选（左侧日历）

- 日历默认是 **单选日期**：点一个日期只看那天的照片；再点别的日期直接切换（不会累积多选）。
- 点 **「全部日期」** 回到全部照片。
- **亮起的日期** 表示当天有照片；灰色日期不可点击。用 ‹ › 切换月份。

### 左侧人物面板

- 显示识别引擎与扫描状态，可在这里 **扫描人物**、取消扫描；点「显示全部人物」展开人物气泡，点击某个人物头像只看 TA 的照片；「清除人物筛选」恢复全部。
- 详细的人物管理在 **人物查找** 页面（见第 6 节）。

### 筛选栏（主区上方）

- **智能搜索**：一个输入框两种用法——
  - 输入文件名或路径 → 直接匹配；
  - 输入自然语言描述（如"海边日落"）→ 语义搜索（本地 AI，首次查询需要先建立索引，有进度提示）。
  - 右侧下拉可切换搜索模式，搜索中有进度条和「取消」按钮。
- **分类 Chips**：全部 / RAW生图 / JPG生图 / 修后 / 视频 / action视频 / 素材，点一下选中，再点取消。
- **修图状态**：全部 / 已修 / 未修 三段选择。
- **评分分类**：下拉选择 全部评分 / 未评分 / 1★~5★。
- **多选模式**开关：开启后单击即可勾选多张。
- **⚙ 高级筛选**：折叠面板，包含——
  - 显示方式（网格 / 树图等）；
  - 面积（树图模式下矩形大小的计算方式）；
  - 排列方式（排序）：默认顺序 / 文件名 A–Z / Z–A / 文件从小到大 / 从大到小 / 分类 / 评分高低 / **拍摄时间从新到旧** / 从旧到新；
  - 智能识别：选择识别引擎、智能类别筛选、「识别所选」「识别当前范围」「停止」按钮。
- 所有筛选条件同时生效（取交集），点顶部 **「重置」** 一键清空。

### 照片墙（网格视图）

- 默认按日期分组展示缩略图，点日期分组标题可展开 / 收起。
- 每张卡片显示：缩略图、**类型角标**（RAW/JPG/PNG/视频等）、**已修 / 未修角标**；视频有播放图标；缩略图足够大时还会显示文件名、备注、智能类别与手动标签。
- **缩放缩略图**：`Ctrl + 鼠标滚轮`，或使用左侧底部「缩略图大小」滑杆（48–512px）。
- **单击**：选中照片，右侧 Inspector 显示文件信息、拍摄参数、时间与位置，以及快捷操作（评分、标签、打开、打开文件夹、复制路径、移入回收站）。
- **双击**：在应用内打开 **照片查看器**（见第 7 节）。
- **框选多选**：在空白处按住左键拖出选框，框内的照片全部选中；配合 `Ctrl` / `Shift` 可以追加、范围选择。
- **勾选多选**：每张卡片左上角有勾选框，勾选后可在 Inspector 中做批量操作（批量复制 / 移动 / 智能识别 / 归入分类 / 添加标签 / 移入回收站 / 清除选择）。

### 树图视图（空间树图）

- 在高级筛选 → 显示方式里切换。照片按类别显示成大小不同的嵌套矩形，**类别矩形越大说明该类别文件越多**。
- 点击类别矩形进入子类；顶部面包屑可逐级返回。
- 按住 `空格` + 左键拖动平移；滚轮缩放；双击照片打开查看器。
- 扫描过程中矩形大小会持续更新。

### 右键菜单

在照片上点右键：打开 / 评分（1–5 星或删除标记）/ 标签（人像、风光、废片、清除）/ 在文件资源管理器中打开 / 复制路径 / 移入回收站 / 批量复制到… / 批量移动到… / 批量删除选中。

### 删除与快捷键

- **Delete**：删除所选照片，**始终弹确认框，且进入 Windows 回收站**（可恢复）。
- **Ctrl + F**：在浏览页聚焦智能搜索框。
- **Esc**：关闭当前浮层或取消操作。
- 右下角显示「共 N 项」。

## 5. 自定义相册

自定义相册是 **虚拟相册**：添加的只是"引用"，移除相册 **绝不会删除磁盘里的文件夹或照片**。

### 创建相册

- 进入「自定义相册」页：卡片流总览界面，点虚线 **「新建相册」** 卡片（或右下角 ＋ 按钮）→ 选择任意磁盘文件夹 → 相册即创建成功（同一路径不会重复添加）。
- 相册卡片显示封面、名称、路径；如果文件夹不可访问，会显示 ⚠ 角标。

### 管理相册

- 点击相册卡片进入详情：
  - **重命名**：在名称输入框修改显示名，点「重命名」保存（只改显示名，不影响磁盘）。
  - **刷新**：重新扫描相册目录，更新照片。
  - **移除引用**：从应用列表移除相册，不删除磁盘文件。
  - 照片墙支持网格 / 列表两种显示，点击照片右侧 Inspector 显示拍摄信息。

### 浏览规则

- 浏览时会 **递归扫描** 相册目录及其所有子目录中的图片，完全只读。
- 相册清单保存在本机应用数据目录（`custom-albums.json`），不会进入照片目录或网盘。

## 6. 人物查找

人物页有 **两个标签**：「人物相册」和「按脸查找」。

### 人物相册（Tab 1）

1. 点右上 **「扫描人物」** 开始在本机扫描全部照片中的人脸；顶部状态条显示识别引擎、进度和汇总（N 个人物 · M 张含人脸照片）。扫描中可以「取消扫描」。
2. 扫描完成后显示 **圆形头像网格**，每人一个头像 + 姓名 + 照片数。
3. 点击某个人物进入详情：
   - 顶部 hero：大头像、姓名（可直接编辑，点 **「保存姓名」** 生效）、照片总数。
   - **「合并到…」**：把当前人物并入另一个人物（用于同一个人被识别成多个相册时），合并后当前人物删除，照片归入目标人物。
   - 下方照片网格（虚拟化滚动，大量照片也流畅），**双击照片** 在查看器中打开。

### 识别引擎说明

- 默认引擎：**YuNet 人脸检测 + SFace 人脸识别**（内置 ONNX 模型，开箱即用，全部本机运行）。
- 可选引擎：**ArcFace R100**（需在 设置 → 高级 → 人脸识别 里自行提供检测器 / 识别器 ONNX 模型文件，并勾选确认许可；匹配阈值默认 0.45，越高越严格）。
- 引擎和阈值可随时在 **设置 → 高级 → 人脸识别** 中调整。

### 按脸查找（Tab 2）

1. **选择参考照片**：拖入一张人脸照片，或点「选择参考照片」；建议用脸部清晰、接近正面的照片。
2. **选择查找范围**：全部照片，或「选择查找文件夹」指定目录。
3. **调节匹配强度**：滑块 0.30–0.72，越高越严格；找不到结果时往左调低。
4. 点 **「开始查找」**：结果显示在右侧网格中，每张带 **相似度徽章**（如 92%），**双击打开**；可随时「停止」或「清除参考图」。
5. 全程 🔒 **仅在本机运行**，照片不外传。

## 7. 照片查看器

双击照片墙 / 人物照片 / 按脸查找结果中的照片，会在应用内打开 **无边框沉浸式查看器**（黑底、无系统标题栏）。

### 工具栏（自动隐藏）

- 工具栏默认隐藏；**移动鼠标** 即调出，**3 秒无操作自动隐藏**（鼠标悬停在工具栏上或信息面板打开时不会隐藏）。
- 工具栏是带亚克力模糊的玻璃胶囊，照片透过来呈模糊质感。

### 顶栏

- 左上：**返回图库（Esc）** + 文件名 + 当前位置。
- 右上：**全屏（F11）** + **关闭（Esc）**。

### 底栏

- **上一张 / 下一张**：`←` / `→`（或点按钮）。
- **缩小 / 放大 / 适应**：鼠标滚轮缩放，双击照片恢复适应窗口；点「适应」一键回到适应大小。
- **打开源文件夹**：在资源管理器中定位文件。
- **信息按钮**：调出右侧详细信息面板。

### 视频播放（MP4 / MOV 等）

打开视频后自动进入播放模式，底栏出现视频控制组：

| 操作 | 方式 |
|---|---|
| 播放 / 暂停 | 空格，或点播放按钮 |
| 后退 10 秒 | `Shift + ←`（或点按钮） |
| 快进 10 秒 | `Shift + →`（或点按钮） |
| 拖动进度 | 拖进度条，旁边显示当前时间 / 总时长 |
| 倍速 | 点倍速按钮循环切换 **0.5x → 1x → 1.25x → 1.5x → 2x**（个别媒体不支持时保持 1x） |
| 音量 | 拖动音量条（默认 80） |
| 静音 | 点喇叭按钮切换 |

> 视频用系统级播放内核（LibVLC），请确保系统媒体组件正常；工具栏出现时视频画面会自动让出工具栏区域，保证按钮可点。

### 详细信息面板

点底栏「信息」按钮从右侧滑出，包含：

- **评分**：1–5 按钮（也支持键盘数字键 1–5 直接打分）。
- **移入回收站**：红色按钮（Delete 键等效，始终确认并进回收站）。
- **文件信息**：大小、分辨率、拍摄时间。
- **拍摄参数**：ISO、光圈、快门、焦距。
- **设备与位置**：相机、镜头、位置。

### 键盘快捷键汇总

| 按键 | 作用 |
|---|---|
| ← / → | 上一张 / 下一张 |
| Shift + ← / → | 视频后退 / 快进 10 秒 |
| 空格 | 视频播放 / 暂停 |
| F11 | 全屏（再按或 Esc 退出；全屏时 Esc 先退出全屏） |
| Esc | 关闭查看器（返回图库） |
| Delete | 移入回收站（确认后） |
| 1–5 | 评分 |
| 滚轮 / 双击 | 缩放 / 适应窗口 |
| 按住左键拖动 | 放大后平移照片 |

## 8. 图片小工具（压缩 / 拼图 / 水印 / 微信发送）

左侧导航「图片小工具」进入工具落地页，有 **4 张卡片：图片压缩、图片拼图、批量水印、微信发送**。点击卡片进入该工具的工作台，点「← 返回工具」回到卡片页。右侧 Inspector 显示运行统计（输入数量 / 原始总大小 / 输出总大小 / 进度）。

### 图片压缩（批量）

- 拖入图片或文件夹（文件夹自动扫描全部子目录）。
- **压缩设置**：目标模式二选一——
  - **每张图片上限**：每张压到指定大小以内；
  - **整批总大小**：整批压到合计目标大小以内。
- 压缩 **保持原始像素尺寸**（不改变分辨率），自动挑选满足大小上限的最高质量；适合微信 / 网盘分享前批量瘦身。
- 指定输出目录 → 开始压缩，进度条实时显示。

### 图片拼图

- 拖入图片，**不限张数**，按队列顺序拼接；选择 **纵向拼接 / 横向拼接**。
- 保留每张图片原本大小；可选「限制输出文件大小」（只调整 JPEG 编码质量，不改变拼图像素尺寸）。

### 批量水印

- 两种模式：**图片列表**（批量选图 / 拖入）与 **文件夹批处理**。
- **水印形式**：单个签名 / 多个铺满（平铺），透明 PNG 图片水印。
- 调整：**透明度**、快速位置（九宫格）、预览中 **单击或拖动定位**；铺满模式支持手动精细调节间距 / 角度。
- 处理时 **保持原始格式、分辨率与长宽比，保留 EXIF / GPS / ICC**。
- 支持「单张特别调整」：为个别图片单独设置参数后处理。
- 点「开始批量处理」执行。

### 微信发送（原图）

- 原图发送队列：**每批最多 9 张**，**不压缩、不转码**。
- 应用自动检测微信桌面客户端、定位目标聊天；**结果不确定时安全暂停**，由你确认后再发。
- 需要本机已安装并登录微信桌面版。

## 9. 网盘（百度 / 夸克）

网盘页顶部可切换 **「百度网盘」/「夸克网盘」**。页面主区是 **内嵌浏览器**（WebView2），右侧 320px 是云盘总览面板。

### 内嵌浏览器（两盘共用）

- 顶部一排按钮：**后退 / 前进 / 刷新 / 首页**。
- 加载中 / 加载失败 / 超时（20 秒）会显示状态面板，失败时可点 **「重试」**。
- 浏览器自动跟随应用的明暗主题。
- 如果初始化目录被占用（上一次进程未完全退出），应用会 **自动改用独立子目录重试**，一般无需手动处理。

### 百度网盘

- 切换后自动打开 `pan.baidu.com`，**直接在网页里登录**（扫码 / 账号密码均可，登录态由浏览器保存）。
- 登录后即可在网页里浏览、上传、下载、管理网盘文件——这些操作走的是百度官方网页，和平时用浏览器一样。
- **右侧云盘总览**：显示账户卡片与连接状态、容量使用环（已用百分比）、统计与传输队列。它的数据来自百度网盘 API 会话：
  - 在 **设置 → 云盘与项目 → 百度网盘** 填入 **AppKey / AppSecret**（在百度网盘开放平台创建应用获得）→ 点「保存凭据」（凭据用 Windows 本机加密保存，不上传）→ 点「授权」按提示完成授权。
  - 授权成功后，云盘页右侧会显示真实账户与容量；未授权时如实显示 **「未登录 · 未找到已保存的 API 会话」**，网页浏览不受影响。
  - 需要解除时点「断开连接」。
- 说明：**「已同步」「本月上传」暂无统计源**，显示 —；传输队列来自本地任务队列，当前暂无实际传输任务，会显示「暂无传输任务」。

### 夸克网盘

- **应用内已集成夸克网盘连接器**（基于夸克官方开放平台 CLI），右侧云盘总览显示真实夸克账户状态：
  - **未登录**：如实显示「未登录 · 请先完成夸克网盘授权」；账户卡片下方会出现 **「登录夸克网盘」** 按钮，点击后启动浏览器完成 OAuth 授权，授权成功后自动刷新账户状态。
  - **已登录**：显示真实昵称、已用容量 / 总容量、文件列表与传输队列。
- 页面主区仍是内嵌浏览器（`pan.quark.cn`），可在网页里浏览、上传、下载；右侧总览与文件操作走夸克官方开放平台接口（CLI）。
- 使用前提：本机需安装 **Node.js（≥ 16）**；应用首次调用夸克接口时会检测 CLI 可用性，缺失时如实提示。
- 应用 **永远不会** 做截取 Cookie、扫码自动化、验证码自动化、私有 API 反编译这类操作。

## 10. 设置

设置页左侧是分区导航，右侧是设置项，最右是常驻 Inspector（主题预览 / 数据存储 / 关于）。修改大多即时保存。

### 外观

| 设置 | 说明 |
|---|---|
| **主题 · 6 套色卡** | 动态色彩 / 森林绿 / 紫罗兰 × 浅色 / 深色。点击色卡 **立即全局换肤**，右侧 Inspector 同步实时预览；当前主题带 ✓ 标记，选择自动记忆 |
| 导航菜单显示 | 文字 / 图标 / 图标和文字 |
| 背景来源 | 跟随主题 / 自定义图片 / 纯色 |
| 背景显示方式 | 填充 / 居中 / 保持长宽比 / 拉伸 |
| 玻璃强度 | 滑杆 0.25–0.95，调节背景模糊与半透明程度 |
| 亚克力材质 | 开关：启用系统级亚克力背景模糊（**Windows 11 优先使用 DWM 原生效果**；Windows 10 自动降级为系统亚克力；再不支持则用应用内半透明玻璃） |
| 自定义背景 | 「选择自定义背景」用本地图片做窗口背景，「清除背景」恢复 |
| 窗口图标 | 选择 / 清除自定义的应用窗口图标 |

### 常规

- **开机自启动**：写入当前 Windows 用户的启动项（失败会自动回滚并提示）。
- **恢复上次窗口状态**：恢复宽度、高度、位置与最大化状态（位置不可见时自动校正）。
- **再次查看新手指南**：重新播放引导。
- **版本与更新日志**：版本树 + 各版本更新说明。

### 照片库与导入

- **照片库根目录**：查看当前库路径，「更改照片库」重新选择（修改后自动重新扫描）。
- 显示库健康状态与已发现日期数。
- 启动时自动验证照片库并后台扫描新文件。

### 浏览与 AI

- **浏览默认值**：默认评分筛选、默认排序、浏览进入恢复策略（回到上次位置 / 首页）、全局默认缩略图尺寸（96–260px）。这些默认值不会被当前浏览会话覆盖。
- **AI 识别**：默认识别引擎（本地 **Chinese-CLIP** · ONNX Runtime，照片不出本机）、每张照片的语义标签数量、语义搜索相似度窗口（越小越严格）。

### 云盘与项目

- **百度网盘**：AppKey / AppSecret 输入框、「保存凭据」「授权」「断开连接」（见第 9 节）。
- **夸克**：官方客户端位置、「打开官网」。应用内夸克连接器已集成（第 9 节），未登录时可在云盘页点「登录夸克网盘」授权。

### 高级

- **性能**：推理设备（自动 / CPU；GPU 不可用时自动回退 CPU，不影响已有识别进度）。
- **人脸识别**：识别引擎（YuNet+SFace 内置 / ArcFace 自备）、性能模式（快速 / 精准）、ArcFace 检测器与识别器 ONNX 路径、匹配阈值（默认 0.45）、模型许可确认。
- **存储与诊断**：设置、主题、元数据、人物相册、地图缓存与云会话均在本机应用数据目录（只读展示，当前不提供清理 / 迁移）。
- **快捷键**：Ctrl + 滚轮（缩略图尺寸）、Delete（删除到回收站）、Esc（关闭浮层 / 取消）。
- **安全与隐私**：云凭据本地加密；本地 AI 在设备上运行；删除确认始终启用且不可关闭。

### 关于与支持

- 设置页右侧：版本、构建（net8.0-windows）、许可（个人使用）。
- 支持作者：微信赞赏码（点击看大图）、爱发电主页。

## 11. 常见问题

### 设置损坏导致启动闪退 / 设置丢失？

- 如果 `settings.json` 被外部修改或写坏（非法 JSON 等），应用 **不会闪退**：启动时会自动把损坏文件备份为 `settings.json.corrupt-时间戳`，并回退到默认设置继续运行。之后重新设置一次即可。

### 网盘页打不开 / 提示"云服务暂时无法打开"？

- 内嵌浏览器初始化时如果遇到目录被占用（常见于上一次进程未完全退出，错误码 0x8007139F），应用会 **自动改用独立唯一子目录重试一次**。
- 若仍失败，通常是网络或 WebView2 运行时问题：检查网络、完全退出应用后重开，或在状态面板点「重试」。

### 云盘右侧显示"未登录 / 未接入"？

- 百度：需要在 **设置 → 云盘与项目** 填 AppKey / AppSecret 并完成授权；未授权时如实显示未登录（网页浏览不受影响）。
- 夸克：应用内夸克连接器已集成（见第 9 节），未登录时在云盘页点「登录夸克网盘」完成授权；本机需安装 Node.js（≥ 16）。

### 视频打不开或没有声音？

- 视频播放依赖系统媒体组件（LibVLC）。请确认系统组件正常；个别容器或编码不支持的视频无法播放属正常现象。
- 倍速在个别媒体上可能无效，此时会保持 1x，不影响播放。

### 删错了照片怎么办？

- 所有删除操作都会先弹确认框，且文件进入 **Windows 回收站**，打开回收站即可还原。
- 「修后」目录受只读保护，任何操作都不会写入或覆盖其中的文件。

### 语义搜索（智能搜索）很慢？

- 第一次使用语义搜索时，应用需要在后台为照片库建立语义索引，请等待进度完成；之后搜索会快很多。也可以只对所选照片或当前范围做「识别」，增量建立标签。

### 人物识别不准确 / 识别不出？

- 识别引擎默认 YuNet + SFace；可在 **设置 → 高级 → 人脸识别** 调高 / 调低匹配阈值（默认 0.45，越高越严格、误报越少）。
- 同一个人被分成多个相册时，用人物详情里的 **「合并到…」** 合并。
- 需要更高精度可自备 ArcFace R100 模型（需自行提供并确认许可）。

### 照片库打不开？

- 首页 / 设置会显示照片库健康状态。如果照片库是网络路径（如 NAS），请先确认该网络位置已挂载可访问，再「刷新」或重新选择照片库。
- 修改照片库根目录后应用会重新扫描，首次进入浏览页可能需要一些时间。

### 导入时提示"需要人工确认"？

- 说明该文件无法自动判断归属 / 分类，应用会停下来让你确认，绝不会乱放。在队列卡片里手动选择分类或取消勾选即可。
