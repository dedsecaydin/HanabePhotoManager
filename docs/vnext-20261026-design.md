## 方案比较

1. **推荐：按工作流逐项交付。** 先数据安全与场次，再拼图、视频、最后统一入口与性能回归。每阶段有可运行版本及测试，风险容易隔离。
2. 先整体改 UI 再接功能：视觉更早统一，但易出现空入口和较大回归面，不推荐。
3. 先迁移全部存储并建立通用处理平台：长期一致性较高，但当前证据不支持成本和风险，不采用。

## 场次设计

- Core 负责确定性排序、阈值分割、边界编辑与合并；Infrastructure 负责元数据读取适配和版本化持久化；App 使用独立场次 ViewModel。
- 默认阈值 30 分钟，只有相邻时间差严格大于阈值才分开；等于阈值不分开。排序稳定，同时间按规范化文件名及稳定成员标识消歧。
- 检测顺序始终为拍摄时间；用户切换日期/文件名排序只改变展示，不暗改检测结果。
- 有可靠偏移的时间归一到同一时间基准；无偏移时保留相机本地时间语义，禁止猜测为电脑时区。混合时区、不同相机疑似时钟偏差和缺失时间列入待确认组。用户可设置每相机时间修正，仅保存修正配置，不回写 EXIF。
- 导入结束只汇总一次；预览范围、数量、异常和成员。手动增删边界、合并后再确认。取消预览无持久化变化。
- 场次提交保存成员和变更前快照、修订号；撤销校验修订号，防止覆盖后续编辑。持久化失败不显示成功；重启后可恢复最近已提交操作的撤销信息。
- 场次数据采用独立版本化存储，不重写旧图库索引。通过 Core 存储接口隔离文件格式；恢复备份在副本中验证。未知版本拒绝写入，损坏时保留文件并报告，禁止静默清空。
- 场次模块不提供移动原片能力。未来物理移动/重命名必须走已有安全文件操作及单独确认。
- 导入列表和关系图继续共享现有日期决策对象及确认命令，不引入第二套导入计划。

## 拼图设计

- 保留原输入顺序；拖动、时间排序、文件名排序均产生显式顺序，锁定后候选生成不改变顺序。
- Core 输出与图像库无关的矩形、缩放和裁切计划；提供规则网格、自适应行、主图杂志、长图四类布局。生成三套不同且可复现的候选；重新生成改变布局参数而非偷偷改变照片顺序。
- 默认完整适配，允许留白，不拉伸。裁切为显式选项；启用后可参考现有人脸和主体区域。AI 失败时返回几何候选并标记未使用主体建议。
- 主图、交换、边距、间隔、背景色、画布比例均参与同一预览/导出计划。
- 输出 JPG、PNG、TIFF；先探测尺寸与像素预算，再逐张解码合成，不同时持有全部原尺寸图片。取消清理临时产物，最终发布不覆盖已有文件。
- 混合 ICC 不可直接复制任一输入配置。统一至明确输出空间；缺少可验证的转换能力时明确提示并阻止声称色彩准确，保留原图。用带 ICC 的样片验证色彩路径。

## 视频设计

- 单一不可变处理配置描述输入传递函数、源色域、LUT/标准变换、输出色域、位深、色度采样、分辨率、帧率、编码器和质量控制。预览与导出共用色彩滤镜构建器；预览仅改变时长及可说明的编码速度参数。
- 不从文件名猜 S-Log3。读取可靠元数据；无法确定时由用户选择 S-Gamut3.Cine / S-Gamut3。自定义 LUT 要求明确输入/输出约定；拒绝格式错误和不匹配选项。
- 标准 Rec.709 预设须附可复现的变换来源与测试样本。编码器标签只描述输出，不能代替实际色彩变换。
- 10-bit 优先保留高精度滤镜与 H.265 10-bit 输出；H.264 或硬件仅支持 8-bit 时明确提示。HDR/SDR 与色度采样降级在开始前展示。
- 用编码器枚举加小型实际编码探测判断 NVENC/AMF 能力；不能将名字出现在列表当作可用。保留软件编码。硬件失败记录原因，用户可选择软件回退并仅重试失败项目。
- 节省空间、高质量和自定义预设；目标码率与恒定质量互斥，参数按编码器映射；默认保持源分辨率和帧率。
- 全应用默认一个重型编码任务，其他排队；等待也可取消。任务持久化冻结输入配置、状态和错误，完成后探测输出参数再发布。重启时未完成任务标为可重试，不自动重复成功任务。
- 用户素材只读，输出唯一命名，临时文件在 D 盘配置目录；取消终止进程并等待释放文件。处理日志不得包含密钥或凭据。

## UI 与兼容性

- 素材管理整合导入、排序、场次入口；拼图四步为选图、自动排版、微调、导出；视频参数与队列共用处理工作区。
- 高频项直接展示，位深/色域/码率等放高级区，但必要的色彩歧义确认不能隐藏。
- 复用现有主题、按钮、间距和非阻塞进度；新 ViewModel 不继续堆入 MainWindowViewModel。保留旧入口直至新入口通过回归。
- 当前媒体恢复继续独立，只读扫描及隔离导出不得接入普通批处理写入流程。
- 更新前备份设置和索引，记录版本和校验值，在临时目录恢复验证后才允许迁移。失败保留旧数据，回滚仅涉及应用状态，不动原始素材。
