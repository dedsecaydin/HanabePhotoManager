# Windows 版统一设计（与 macOS 共用一套视觉）

> 接手关键词：`HANABE-WINDOWS-UNIFIED-UI`
> 设计稿：https://claude.ai/artifact/BFcTYGVkbXMZaSwa7v3VPF （画布的 “Windows” 页：主页 · 导入检查确认 · 照片图库 · 设计规范与改动）
> 共享令牌与组件规则见 `docs/macos-port/design.md` 第 2 节；本文件只写 Windows 不同的地方和要改什么。
> **只换外观和布局，所有功能、逻辑、文字、导入流程不变。** 每改一页都跑 `dotnet build` + `dotnet test`，并用隔离数据启动截图对照设计稿（方法见 `AGENT_HANDOFF_MACOS.md` 第 5 节）。

## 1. Windows 专属规则

| 项 | 规定 |
|---|---|
| 标题栏 | 48 px，左：汉堡按钮（Ctrl+B 收起侧栏）+ 22 px Logo + “Hanabe 照片工作台”；正中：搜索框 460×34（底边 1 px 白 30%，聚焦时变强调色）；右：通知、最小化 / 最大化 / 关闭（46 px 宽，系统样式） |
| 材质 | 窗口底用 Mica（现有 `ApplyWindowMaterial` 保留），叠加 Hanabe 渐变；内容区是一块左上圆角 8 的面板（白 0 + 黑 18%，上 / 左 1 px 白 8%），像 Windows 11 设置 |
| 侧栏 | 宽 240 / 窄 64；项高 40、圆角 6、字号 14；选中 = 强调色 18% 底 + 左侧 3×18 强调色竖条；底部只放“浅色 / 设置”；去掉大 Logo 卡和底部 “Keep memories” 卡 |
| 尺寸 | 正文 14 · 区块标题 18 · 页面标题 32 · 说明 12；按钮 / 输入 36 高、圆角 6；卡片圆角 12；页面边距 30 |
| 字体 | Segoe UI Variable + Microsoft YaHei UI；手写体只在主页 Hero 出现 |
| 阴影 | 卡片去掉投影，只用描边与透明度分层；只有右键菜单、弹出面板、对话框有投影 |
| 快捷键 | Ctrl+B 侧栏 · Ctrl+K 搜索 · Ctrl+Enter 问 AI · Delete 回收站 · 1–5 评分 · 空格预览 · Ctrl+1…9 切页（新增） |

## 2. 要改的页面（按顺序）

1. **外壳（MainWindow.xaml 顶部 + 侧栏）**：按第 1 节重排标题栏和侧栏；删除每页的“手写英文 + 大标题 + 说明”三行页头，改成页面内一个 32 px 标题（导入页标题右侧放三步胶囊）。现有 `SidebarClip` 动画、右键菜单显示 / 隐藏功能页、窄侧栏设置全部保留。
2. **主页**：两列（左 Hero + 拍摄频率 / 交付进度两卡，右 380 px 长卡：日程、存储空间、当前连接设备）。桌面助手开关放进 Hero 按钮行。
3. **导入页**：结构已经是三步 + 日期卡片，只按新尺寸、圆角、颜色调整；数字卡的“重复”卡用强调色 12% 底。
4. **照片图库**：默认窄侧栏；左侧日期列 220（按月分组，项高 34）；中间工具栏放“网格 / 平铺 / 矩形树图”和分类分段控件；新增右侧信息面板 290（预览、文件名 + 伴随文件、评分、EXIF、人物 / 标签胶囊、快捷键提示），Ctrl+I 开关，状态记住。
5. **人物、地图、工具、相册、日期文件夹、设置**：套用同一套规则；人物页结构按 macOS 稿（已命名大头像一排、未命名小头像、路人提示条）。
6. **主题**：所有主题色板只改令牌值，不改键名；检查浅色主题下对比度（正文 4.5:1）。

## 3. 验收

- 全量测试通过；Windows 版逐页截图与画布对照；窗口 1024×680 最小尺寸下不出现横向滚动或被裁切的按钮。
- 侧栏收起 / 展开动画、主题切换动效、桌面助手、右键菜单行为不变。
- 在 `docs/agent-change-log.md` 记录。
