# Hanabe Photo Manager 功能简介

Hanabe Photo Manager 是一款以本地隐私为核心的 Windows 照片与视频管理工具。它将相机文件导入、按日期浏览、智能分类、人脸相册、修后文件管理和地图照片整合到一个统一的苹果风格界面中。

## 主要功能

### 照片库与导入

- 扫描本机磁盘、移动设备和指定照片库。
- 按拍摄日期整理照片与视频，并识别 RAW、生图、修后文件、视频和素材。
- 自动删除不含任何照片、视频或有效内容的空日期目录；无内容日期在日历中显示为灰色且不可点击。
- 修复按具体日期筛选“修后”时漏掉实际修后文件的问题。

### 浏览与批量操作

- 统一的照片墙、日期日历、搜索、排序和缩略图缩放。
- 支持长按左键框选；拖到视图上下边缘时自动滚动，可连续选择屏幕外内容。
- 所有滚动条使用统一的高对比轨道与清晰滑块，能明确看到当前位置和可滚动范围。

### 本地智能分类

用户可在两种完全本地的识别方案间切换：

- **轻量规则识别**：结合人脸检测、颜色、亮度、边缘和 EXIF 信息判断类别，启动快、占用小。
- **本地 ONNX 多标签识别**：使用本地视觉模型识别人像、风景、城市、建筑、夜景、动物、美食等类别，结果缓存在本机。

识别失败或结果不准确时，可以手动修改分类、添加已有标签，或创建自定义标签；人工结果优先，不会被后续自动分析覆盖。

### 人物相册

- 在浏览页左侧以圆形头像展示本地识别的人物分组。
- 初次识别使用 A、B、C 等临时名称，支持直接重命名。
- 人脸检测、特征提取、聚类和相册数据均在本机完成。

### 地图照片

- 从照片 EXIF GPS 信息识别拍摄位置，并在地图上聚合展示。
- 没有 GPS 信息的照片可由用户手动输入经纬度分配位置，也可重新修改或清除。
- 照片、文件路径、标签和位置记录始终保存在本机；联网仅用于加载 OpenStreetMap 地图瓦片。
- 地图支持缩放、鼠标拖拽平移和聚合标记浏览。

### 视觉与个性化

- 统一的苹果风格深色玻璃界面、圆角控件和状态反馈。
- “跟随 Windows 壁纸”会读取当前系统壁纸，并透过半透明背景和玻璃面板真实显示。
- 应用窗口、标题栏和任务栏使用统一的 Hanabe 图标。

## 隐私说明

智能分类、人脸识别、元数据、人物命名、手动标签和位置数据均在本机处理与保存。程序不会把照片或本地路径上传到地图服务；启用地图时，仅向地图瓦片服务请求当前视图所需的公开底图图片。
